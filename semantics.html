Introduction

What is HTML?

HTML stands for HyperText Markup Language. It is used to create the structure of web pages.

Syntax

<!DOCTYPE html>
<html>
<head>
<title>My Page</title>
</head>
<body>

<h1>Hello World</h1>

</body>
</html>

Document Structure

Every HTML document contains:

  • <!DOCTYPE html>
  • <html>
  • <head>
  • <title>
  • <body>

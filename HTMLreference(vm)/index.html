1.What is HTML?

HTML (HyperText Markup Language) is the standard markup language used to create and structure web pages. It uses tags to define elements such as headings, paragraphs, images, tables, forms, links, audio, and videos. Web browsers read HTML code and display the content on the screen.


Features of HTML

  • Easy to learn and use.
  • Platform-independent (works on all operating systems).
  • Supported by all modern web browsers.
  • Allows embedding of images, audio, videos, and links.
  • Supports forms for collecting user input.
  • Works with CSS for styling and JavaScript for interactivity.

2.History of HTML

  • 1991:HTML was created by **Tim Berners-Lee.
  • 1995:HTML 2.0 became the first official HTML standard.
  • 1997:HTML 3.2 introduced support for tables, applets, and scripting.
  • 1999: HTML 4.01 added improved support for style sheets, scripting, and accessibility.
  • 2014:HTML5 became the official recommendation with support for multimedia, semantic elements, and modern web applications.
  • Present: HTML5 is the latest and most widely used version of HTML.

6.HTML Tags

HTML tags are predefined keywords enclosed in angle brackets (`< >`) that define different parts of a webpage, such as headings, paragraphs, images, tables, and forms.


Tag Description
<html> Defines the root of an HTML document
<head> Contains metadata about the document
<title> Specifies the title of the webpage
<body> Contains the visible content of the webpage
<h1> - <h6> Defines headings from largest to smallest
<p> Defines a paragraph
<br> Inserts a line break
<hr> Creates a horizontal line
<div> Defines a block-level container
<span> Defines an inline container

7. HTML Attributes

What are HTML Attributes?

HTML attributes provide additional information about HTML elements. They are written inside the opening tag and modify the behavior, appearance, or properties of an element.

Global Attributes

Global attributes are attributes that can be used with **almost all HTML elements**. They help identify, style, and control elements on a webpage.

Common HTML Attributes

  1. id: Provides a unique identifier for an HTML element.
    * Each `id` value should be unique within a webpage.
  2. class :Assigns one or more class names to an element.
    * Used to group multiple elements with the same name.
  3. style: Adds inline CSS styles directly to an HTML element.
  4. title: Displays additional information as a tooltip when the mouse pointer is placed over an element.
  5. lang: Specifies the language of the content in an HTML document or element.
  6. dir: Defines the text direction of the content.
    * Common values are `ltr` (left-to-right) and `rtl` (right-to-left).
  7. hidden:Hides an HTML element so it is not displayed on the webpage.
  8. tabindex:Specifies the order in which elements receive focus when the **Tab** key is pressed.

Importance of HTML Attributes

  • Add extra information to HTML elements.
  • Improve accessibility and usability.
  • Help identify and organize elements.
  • Control the behavior and presentation of webpage content.

8. HTML Elements

What is an HTML Element?

An HTML element is the complete structure consisting of a **start tag**, **content**, and an **end tag**. Elements define the structure and content of a web page.

Structure of an HTML Element

  1. Opening Tag:Marks the beginning of an element.
  2. Content:The text or other elements inside the tags.
  3. Closing Tag:Marks the end of the element.

Importance of HTML Elements

  • Define the structure of a webpage.
  • Organize content into meaningful sections.
  • Help browsers display content correctly.
  • Improve readability and maintainability of web pages.

10. Interview Questions

1. What is HTML?

Answer: HTML (HyperText Markup Language) is the standard markup language used to create and structure web pages.

2. What does HTML stand for?

Answer: HTML stands for HyperText Markup Language.

3. Is HTML a programming language?

Answer: No. HTML is a markup language used to structure web pages. It does not perform programming logic.

4. Who developed HTML?

Answer: HTML was developed by Tim Berners-Lee in 1991.

5. What is the latest version of HTML?

Answer: HTML5 is the latest version of HTML.

6. What is a Web Page?

Answer: A web page is a single HTML document displayed in a web browser.

7. What is a Website?

Answer: A website is a collection of related web pages connected through hyperlinks.

8. What is a Web Browser?

Answer: A web browser is software used to access and display web pages.

9. What is a Web Server?

Answer: A web server stores website files and delivers them to users over the Internet.

10. What are HTML Tags?

Answer: HTML tags are predefined keywords enclosed in angle brackets that define webpage elements.

11. What are HTML Elements?

Answer: An HTML element consists of a start tag, content, and an end tag.

12. What are HTML Attributes?

Answer: HTML attributes provide additional information about HTML elements and are written inside the opening tag.

13. What is the purpose of <!DOCTYPE html>?

Answer: It tells the browser that the document follows the HTML5 standard.

14. What is the basic structure of an HTML document?

Answer: The basic structure includes <!DOCTYPE html>, <html>, <head>, <title>, and <body>.

15. What is the difference between HTML and HTML5?

Answer: HTML5 supports multimedia, semantic elements, local storage, and modern web features, while older HTML versions have limited capabilities.

16. What is the purpose of the <head> tag?

Answer: The <head> tag contains metadata such as the page title, character encoding, CSS links, and JavaScript files.

17. What is the purpose of the <body> tag?

Answer: The <body> tag contains all the visible content displayed in the browser, such as text, images, tables, and forms.

18. What is the difference between HTML tags and HTML elements?

Answer: A tag is the markup enclosed in angle brackets (e.g., <p>), whereas an element includes the start tag, content, and end tag.

19. Why is HTML important?

Answer: HTML is the foundation of web development. It structures web pages and works together with CSS for styling and JavaScript for interactivity.

20. Can HTML create dynamic webpages?

Answer: No. HTML creates the structure of a webpage. Dynamic behavior and interactivity are added using JavaScript, while CSS is used for styling.

1.What is HTML Form?

An HTML Form is used to collect user input and send it to a server for processing. Forms are commonly used for login pages, registration, search, feedback, and contact forms.

Why are Forms Used?

  • Collect user information.
  • Submit data to a server.
  • Perform user authentication.
  • Enable user interaction with websites.

Advantages

  • Easy to collect data.
  • Supports different input types.
  • Enables client-side validation.
  • Improves user interaction.

2.Form Structure

An HTML form consists of:
  • Form
  • Labels
  • Input fields
  • Buttons
  • Selection controls
  • Validation attributes

3.HTML Form Tags

Tag Description
<form> Creates an HTML form
<input> Creates an input field
<label> Defines a label for an input field
<textarea> Creates a multi-line text input
<select> Creates a drop-down list
<option> Defines an option in a drop-down list
<optgroup> Groups related options in a drop-down list
<button> Creates a clickable button
<fieldset> Groups related form elements
<legend> Defines a caption for a fieldset
<datalist> Provides predefined suggestions for an input
<output> Displays the result of a calculation

11. Interview Questions

1. What is an HTML Form?

Answer: An HTML form is used to collect user input and send it to a server for processing.

2. Which tag is used to create a form?

Answer: The <form> tag is used to create an HTML form.

3. What is the purpose of the action attribute?

Answer: The action attribute specifies the URL where the form data will be sent.

4. What is the purpose of the method attribute?

Answer: The method attribute specifies how form data is sent to the server, such as GET or POST.

5. What is the difference between GET and POST?

Answer: GET sends data in the URL, while POST sends data in the request body.

6. What is the purpose of the <input> tag?

Answer: The <input> tag is used to create different types of input fields.

7. What is the purpose of the <label> tag?

Answer: The <label> tag provides a label for a form control and improves accessibility.

8. What is the purpose of the <textarea> tag?

Answer: The <textarea> tag is used to create a multi-line text input field.

9. What is the purpose of the <select> tag?

Answer: The <select> tag creates a drop-down list.

10. What is the purpose of the <option> tag?

Answer: The <option> tag defines an item in a drop-down list.

11. What is the purpose of the <button> tag?

Answer: The <button> tag creates a clickable button.

12. What is the purpose of the placeholder attribute?

Answer: The placeholder attribute displays a hint inside an input field.

13. What is the purpose of the required attribute?

Answer: The required attribute makes a field mandatory before submitting the form.

14. What is the purpose of the name attribute?

Answer: The name attribute identifies the form field when data is submitted.

15. What is the purpose of the value attribute?

Answer: The value attribute specifies the default value of an input field.

16. Which input type is used to enter a password?

Answer: The password input type is used to enter passwords.

17. Which input type is used to upload a file?

Answer: The file input type is used to upload files.

18. What is the purpose of the reset button?

Answer: The reset button clears all the values entered in the form.

19. What are HTML forms commonly used for?

Answer: HTML forms are used for login pages, registration forms, contact forms, surveys, and user feedback.

20. Why are HTML Forms important?

Answer: HTML forms allow users to enter and submit data, making websites interactive and enabling communication between users and servers.

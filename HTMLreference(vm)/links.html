1.What is Hyperlink?

A Hyperlink is a clickable text, image, or element that connects one webpage, document, email, phone number, or section of a webpage to another.

Why are Hyperlinks Used?

  • Navigate between web pages.
  • Open external websites.
  • Download files.
  • Send emails.
  • Make phone calls.
  • Jump to a specific section of a page.

Advantages

  • Easy navigation.
  • Improves user experience.
  • Connects related content.
  • Enhances website usability.

2. HTML Hyperlink Tag

Tag Description
<a> Creates a hyperlink (Anchor tag).

3.Common Attributes

Attribute Description
href Specifies the destination URL
target Specifies where the linked document opens
title Displays additional information on hover
download Downloads the linked file instead of opening it
rel Specifies the relationship between the current and linked document
hreflang Specifies the language of the linked document
type Specifies the MIME type of the linked document
id Unique identifier for the hyperlink
class Assigns one or more CSS classes

4. Types of Hyperlinks

  1. External Link
    2. Links to another website.
    Example Use: Google, YouTube, GitHub.
  2. Internal Link
    3. Links to another page within the same website.
    Example Use: Home → About page.
  3. Bookmark (Anchor) Link
    4. Jumps to a specific section within the same webpage.
    Example Use: Table of Contents.
  4. Email Link
    5. Opens the default email application.
    Example Use: Contact Us.
  5. Telephone Link
    6. Starts a phone call on supported devices.
    Example Use: Customer Support.
  6. Download Link
    7. Downloads a file such as a PDF or image.
    Example Use: Resume download.
  7. Image Link
    8. Uses an image as a clickable hyperlink.
    Example Use: Clicking a logo to return to the homepage

5. target Attribute Values

Value Description
_self Opens the linked document in the same window or tab (default)
_blank Opens the linked document in a new tab or window
_parent Opens the linked document in the parent frame
_top Opens the linked document in the full browser window

6. Applications of Hyperlinks

  • Website navigation

7. Advantages of Hyperlinks

  • Easy website navigation.

8. Interview Questions

1. What is an HTML Link?

Answer: An HTML link (hyperlink) is used to connect one webpage to another webpage, file, email address, or location.

2. Which tag is used to create a hyperlink?

Answer: The <a> (anchor) tag is used to create a hyperlink.

3. What is the purpose of the href attribute?

Answer: The href attribute specifies the destination URL of the hyperlink.

4. What is the purpose of the target attribute?

Answer: The target attribute specifies where the linked document should open.

5. What is the difference between an absolute link and a relative link?

Answer: An absolute link contains the complete URL, while a relative link contains the path to a file within the same website.

6. What is an internal link?

Answer: An internal link connects one page to another page within the same website.

7. What is an external link?

Answer: An external link connects a webpage to another website.

8. What is a bookmark link?

Answer: A bookmark link navigates to a specific section within the same webpage using the id attribute.

9. Which attribute is used to create a bookmark link?

Answer: The id attribute is used with the href attribute to create a bookmark link.

10. What is the purpose of the title attribute in a link?

Answer: The title attribute displays a tooltip when the mouse pointer is placed over the link.

11. What does target="_blank" do?

Answer: It opens the linked webpage in a new browser tab or window.

12. What does target="_self" do?

Answer: It opens the linked page in the same browser tab. This is the default behavior.

13. Can an image be used as a hyperlink?

Answer: Yes. An image can be placed inside the <a> tag to create an image link.

14. Can we link to an email address in HTML?

Answer: Yes. The mailto: protocol is used to create an email link.

15. Can we link to a phone number in HTML?

Answer: Yes. The tel: protocol is used to create a clickable phone number.

16. What are the common attributes of the <a> tag?

Answer: The common attributes are href, target, title, download, and id.

17. What is the purpose of the download attribute?

Answer: The download attribute allows users to download the linked file instead of opening it.

18. What are HTML links commonly used for?

Answer: HTML links are used for navigation, downloading files, sending emails, making phone calls, and connecting web pages.

19. What are the advantages of hyperlinks?

Answer: Hyperlinks improve website navigation, user experience, and access to related information.

20. Why are HTML links important?

Answer: HTML links connect web pages and resources, making websites easy to navigate and use.

1.What is HTML?

An HTML Table is used to display data in rows and columns. It helps organize information in a structured format.

Why are Tables Used?

  • To display tabular data.
  • To compare information.
  • To organize records.
  • To present reports and schedules.

Advantages

  • Organizes data clearly.
  • Improves readability.
  • Easy to compare information.
  • Supports complex data with merged cells.

    9.Interview Questions

    1. What is an HTML Table?

    Answer: An HTML table is used to display data in rows and columns.

    2. Which tag is used to create a table?

    Answer: The <table> tag is used to create a table.

    3. Which tag is used to create a table row?

    Answer: The <tr> tag is used to create a table row.

    4. Which tag is used to create a table header?

    Answer: The <th> tag is used to create a table header cell.

    5. Which tag is used to create a table data cell?

    Answer: The <td> tag is used to create a table data cell.

    6. What is the purpose of the <caption> tag?

    Answer: The <caption> tag provides a title for a table.

    7. What is the purpose of the <thead> tag?

    Answer: The <thead> tag groups the header rows of a table.

    8. What is the purpose of the <tbody> tag?

    Answer: The <tbody> tag groups the main content rows of a table.

    9. What is the purpose of the <tfoot> tag?

    Answer: The <tfoot> tag groups the footer rows of a table.

    10. What is the difference between <th> and <td>?

    Answer: <th> defines a header cell, while <td> defines a data cell.

    11. What is the purpose of the colspan attribute?

    Answer: The colspan attribute allows a cell to span multiple columns.

    12. What is the purpose of the rowspan attribute?

    Answer: The rowspan attribute allows a cell to span multiple rows.

    13. What is the purpose of the border attribute?

    Answer: The border attribute specifies the border thickness of a table.

    14. Can we create nested tables in HTML?

    Answer: Yes. A table can be placed inside another table cell.

    15. What are HTML tables mainly used for?

    Answer: HTML tables are used to display structured data in rows and columns.

    16. What is the difference between HTML tables and HTML lists?

    Answer: Tables display tabular data, while lists display related items in an ordered or unordered format.

    17. What are the advantages of HTML tables?

    Answer: They organize data clearly, improve readability, and present information in a structured format.

    18. Which tags are used to create an HTML table?

    Answer: <table>, <tr>, <th>, <td>, <caption>, <thead>, <tbody>, and <tfoot>.

    19. Is the border attribute recommended in HTML5?

    Answer: No. The border attribute is obsolete in HTML5. CSS should be used for table borders.

    20. Where are HTML tables commonly used?

    Answer: HTML tables are commonly used for student records, employee details, reports, invoices, timetables, and product information.
